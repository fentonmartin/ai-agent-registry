# Pitch Templates Reference

Source: berani-ai-skills/ai-mkt-sales, zarif3624/gtm-skills, louisblythe/Sales-Skills

## Sales Deck Structure (≤10 slides)

| Slide | Content | Goal |
|---|---|---|
| 1 | Problem — customer's world today | Create urgency |
| 2 | Cost of inaction — what happens if nothing changes | Amplify pain |
| 3 | Solution — how we solve it | Position |
| 4 | How it works — 3-step simple explanation | Clarity |
| 5 | Proof — specific customer outcome (metric + named) | Build trust |
| 6 | Why us — differentiator vs alternatives | Reduce risk |
| 7 | Pricing / packages — simple, scannable | Remove friction |
| 8 | ROI snapshot — their numbers, not generic | Justify |
| 9 | Next step — one clear CTA | Advance deal |

## One-Pager Structure
```
[HEADLINE: Customer pain in their language]

THE PROBLEM
2–3 sentences. Their words, not yours.

OUR SOLUTION
1 sentence. What we do and for whom.

HOW IT WORKS
3 bullets. Steps, not features.

PROOF
1–2 specific outcomes. Named customers if possible.

[CTA: One action. One phone/email/link.]
```

## Demo Script — 3-Act Structure

**Act 1: Setup (2 min)**
- Reference their specific pain from discovery
- Set agenda: "I'll show you [outcome], not features"
- Confirm: "Is [pain] still your top priority?"

**Act 2: Aha Moment (5–10 min)**
- Show the workflow that directly solves their pain
- Pause at the key moment: "This is where [X hours/cost] disappears"
- Connect every screen to a buyer pain

**Act 3: Close (3 min)**
- Summarize 3 things they saw
- ROI framing: "Based on what you told me, this would save you..."
- Next step: specific date + action

## Objection Handler Template

```
OBJECTION: "[their exact words]"

ACKNOWLEDGE: "That makes sense — [validate their concern]"

REFRAME: "What I've found is that [alternative frame]"

PROOF: "[specific customer / metric that addresses it]"

BRIDGE: "Given that, would it help to [next small step]?"
```

## Common Objections

| Objection | Reframe | Proof type |
|---|---|---|
| "Too expensive" | ROI > cost; compare to cost of inaction | ROI calc |
| "Not the right time" | Find the critical event creating real urgency | Timeline map |
| "We built it in-house" | Maintenance cost + opportunity cost | TCO analysis |
| "Need to think about it" | Missing information signal — ask what's unclear | Discovery Q |
| "Talk to my team" | Multi-thread — ask to include them in next meeting | Stakeholder map |

## ROI Calculator Inputs

| Input | How to get it |
|---|---|
| Current cost of problem | Ask: "How many hours/week does this take?" |
| Headcount involved | Ask: "Who touches this process?" |
| Frequency | Ask: "How often does this happen?" |
| Error/rework rate | Ask: "What % needs to be redone?" |
| Opportunity cost | Ask: "What could your team do with this time?" |
